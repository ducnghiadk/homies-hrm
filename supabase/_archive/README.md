# Schema đã khai tử

Tất cả file trong thư mục này **ĐÃ KHAI TỬ**. Không được dùng để tạo database, chạy migration, seed dữ liệu, hoặc tham chiếu trong code và tài liệu hiện hành.

Mô hình identity duy nhất của hệ thống là bảng `nhan_vien` được định nghĩa trong `supabase/schema_v3_master_fixed.sql`.

Bảng `employees` và `users` xuất hiện trong các schema đã lưu trữ tại đây **KHÔNG tồn tại trong hệ thống thực tế**.

`rls-policies.sql` thuộc thế hệ `schema.sql`/Genesis đã khai tử. File này **KHÔNG được dùng làm cơ sở cho RLS mới**.
