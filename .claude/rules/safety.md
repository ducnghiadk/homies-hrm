# Safety Rules

## Trước khi sửa
1. Xác định phạm vi file
2. Kiểm tra file có dùng bởi chức năng khác không
3. CHỈ sửa phần liên quan task

## Sau khi sửa
1. Chạy lệnh kiểm tra lỗi
2. Còn lỗi -> sửa hết trước khi báo xong

## KHÔNG được
- Tự rename/di chuyển file nếu không yêu cầu
- Tự refactor code cũ
- Xóa code cũ không hỏi
- Thay đổi logic đang chạy tốt
- Sửa ngoài phạm vi task

## Phát hiện vấn đề ngoài task
- KHÔNG tự sửa, ghi vào Lưu ý, để tôi quyết định
